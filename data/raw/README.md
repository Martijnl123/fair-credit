# Raw data

Put these files in this folder. They are git-ignored.

- `german.data`: UCI Statlog (German Credit Data), https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data
- `default of credit card clients.xls` (UCI, https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)
  or `UCI_Credit_Card.csv` (Kaggle mirror). Either works.
- `application_train.csv`: Kaggle Home Credit Default Risk, https://www.kaggle.com/competitions/home-credit-default-risk/data
  (accept the competition rules first; or `kaggle competitions download -c home-credit-default-risk`).
